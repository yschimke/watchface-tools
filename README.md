# watchface-tools

Shared Kotlin libraries for Wear OS [Watch Face Format](https://developer.android.com/training/wearables/wff)
(WFF, the declarative watch face): a lossless document model, a deterministic XML writer and parser,
version-aware validation and DWF bundle packaging.

Consumed by [compose-ui-builder](https://github.com/yschimke/compose-ui-builder) (the watch-face
design target) and [compose-ai-tools](https://github.com/yschimke/compose-ai-tools) (the DWF render
lanes). The first modules are in progress.
